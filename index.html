Generator Vector Massal
untuk Stock

Halo Ardian — buat puluhan sampai ratusan vector SVG sekaligus untuk microstock. Sekarang bisa berdasarkan daftar prompt kamu sendiri (satu baris = satu desain), dengan nama batch kustom, pilihan gaya vector bawaan, dan gaya versi kamu sendiri — misalnya “ukiyo-e, tinta hitam dan merah” — yang jadi prioritas. Kini bisa diinstal sebagai aplikasi di Android & laptop, lengkap dengan rumusan prompt 7 unsur, preset & riwayat, SEO stock otomatis (Adobe / Shutterstock / Freepik / Canva / Vecteezy / Envato), kurasi favorit sebelum ZIP, import prompt .txt/.csv, palet custom, dan cek duplikasi. Untuk ikon & stiker, pilih latar belakang Transparan agar SVG & PNG-nya tanpa latar dan siap ditempel di mana saja. Unduh satu per satu, atau semua sekaligus dalam satu file ZIP (SVG + PNG + daftar keyword untuk upload stock).

📱 Instal sebagai aplikasi

Pasang di layar utama Android atau laptop — ikon sendiri, tampil penuh tanpa bilah browser, dan tetap bisa dibuka setelah pernah dimuat. Semua generate tetap berjalan lokal di perangkatmu.

Cara instal di Android & laptop

Android (Chrome):

  1. Ketuk tombol Instal Aplikasi di atas, atau buka menu ⋮ di Chrome.
  2. Pilih Instal aplikasi / Tambahkan ke Layar utama.
  3. Ketuk Instal — ikon “Vector Massal” muncul di layar utama & laci aplikasi.

Laptop (Chrome / Edge): klik ikon instal di kanan bilah alamat, atau menu ⋮ → Simpan dan bagikan → Instal halaman sebagai aplikasi.

iPhone / iPad (Safari): ketuk Bagikan → Tambahkan ke Layar Utama.

Setelah terinstal, aplikasi terbuka seperti aplikasi biasa. Generate, kurasi, dan unduh ZIP bekerja di dalamnya; riwayat & preset berlaku selama sesi aplikasi terbuka.

Rumusan Prompt — 7 unsur

Rumusnya: Subjek + Warna + Aksi/Pose + Setting + Waktu & Suasana + Gaya + Komposisi. Makin lengkap promptmu, makin akurat hasilnya — tiap unsur benar-benar mengubah gambar (pose, warna subjek, setting, suasana), bukan sekadar teks.

Tulis prompt dulu — analisis rumusan muncul di sini.

Contoh rumusan lengkap: “Satu kucing oren duduk tenang di bawah pohon sakura saat pagi, gaya flat modern, komposisi tengah, detail sedang, latar transparan.”

Berwarna: latar penuh sesuai palet / gaya — cocok untuk background & pola. Transparan: tanpa latar — cocok untuk ikon, stiker & logo. File SVG tanpa rect latar dan PNG dengan alpha (transparan), siap ditempel di desain apa pun. Di galeri, latar transparan ditandai pola papan catur.

Tips upload ke microstock (Adobe Stock, Shutterstock, Freepik, Vecteezy):
  • SVG adalah format vector utama — bisa diskalakan tanpa pecah. Untuk Adobe Stock / Shutterstock yang meminta EPS, buka SVG di Adobe Illustrator / Inkscape lalu simpan sebagai EPS 10.
  • Pakai judul & keyword dari keywords.csv di dalam ZIP untuk tiap file — keyword sudah disesuaikan per jenis desain.
  • Generate ulang dengan seed baru untuk memperbanyak variasi satu jenis yang paling laku, dan ganti palet agar seri terlihat berbeda.
  • Mode Dari Prompt: satu baris = satu desain. Judul file memakai nama batch + slug prompt, dan daftar prompt lengkap tersimpan di prompts.txt dalam ZIP.
  • Rumusan Prompt 7 unsur: tulis prompt mengikuti rumus Subjek + Warna + Aksi + Setting + Waktu/Suasana + Gaya + Komposisi — contoh: “Satu kucing oren duduk tenang di bawah pohon sakura saat pagi, gaya flat modern, komposisi tengah, latar transparan.” Analisis di bawah daftar prompt menunjukkan unsur yang sudah ada dan yang masih kurang; tombol ✨ Perluas prompt melengkapinya otomatis dari gaya & latar yang sedang aktif. Warna subjek (mis. “oren”), aksi (“duduk”, “terbang”), setting (“di kolam”, “di malam hari”), dan komposisi (“close-up”) benar-benar mengubah gambarnya.
  • Gaya custom jadi prioritas: tulis gayamu sendiri (mis. “ukiyo-e, tinta hitam dan merah”) — warna & teknik yang disebut di situ mengalahkan gaya bawaan dan palet.
  • Latar Transparan untuk ikon: pilih Latar belakang → Transparan sebelum Generate, terutama di mode Dari Prompt. Hasilnya SVG tanpa rect latar dan PNG ber-alpha — ikon terlihat di galeri di atas pola papan catur dan siap ditempel ke desain, presentasi, atau paket ikon stock. Untuk background & pola penuh, tetap pakai Latar Berwarna.
  • Instal aplikasi: pakai tombol Instal Aplikasi di bagian atas (Android Chrome: menu ⋮ → Instal aplikasi). Setelah terinstal, tools terbuka dari layar utama seperti aplikasi biasa.
  • Preset & riwayat: simpan kombinasi gaya + palet + ukuran favoritmu sebagai preset, lalu pakai ulang dari daftar preset atau riwayat batch di perangkat ini.
  • SEO stock: pilih platform (Adobe Stock / Shutterstock / Freepik / Canva / Vecteezy / Envato) di panel SEO, lalu salin judul + keyword per kartu dengan tombol 📋 SEO. Di dalam ZIP ada seo-adobe-stock.csv, seo-shutterstock.csv, seo-freepik.txt, seo-canva.txt, seo-vecteezy.csv, dan seo-envato.txt.
  • Canva & platform grafis lain: hasil generate (SVG + PNG) bisa dipakai di Canva, Figma, Adobe Illustrator, Affinity Designer, Inkscape, dan Vecteezy. Di Canva: buka desain → Uploads → Upload files → pilih file SVG atau PNG-nya, lalu pakai sebagai elemen, stiker, atau logo. PNG transparan paling cocok untuk stiker/logo. Catatan: ganti warna di Canva hanya jalan untuk SVG sederhana berisi warna flat; untuk edit vector penuh, buka SVG di Illustrator / Figma / Inkscape. Di panel SEO, pilih Canva untuk menyalin judul + tag yang sesuai, dan di dalam ZIP ada seo-canva.txt.
  • Kurasi sebelum ZIP: tandai ★ favorit, 🔒 kunci seed desain yang bagus agar tidak berubah saat regenerate, ↻ buat ulang satu kartu saja, ✕ hapus yang jelek — lalu unduh ZIP hanya berisi favorit.
  • Reset Generate: tombol ↺ Reset Generate di bawah panel Pengaturan mengosongkan galeri hasil dan mengembalikan semua pengaturan generate ke awal (mode, jenis, gaya, palet, ukuran, latar). Daftar prompt, preset, dan riwayat batch tidak ikut dihapus, jadi kamu bisa langsung generate ulang dari prompt yang sama.
  • Import & ukuran stock: import daftar prompt dari file .txt/.csv, pilih rasio 1:1 / 4:5 / 16:9 / 3:2, dan export PNG sampai 4000 px.
  • Palet custom & duplikasi: masukkan 5 warna brand kamu di Palet Custom, dan jalankan Cek Duplikasi — kartu yang terlalu mirip dalam satu batch ditandai agar bisa kamu regenerate atau hapus sebelum upload.
  • Semua desain digenerate prosedural di browser ini dan unik per file — tidak memakai gambar pihak ketiga.
